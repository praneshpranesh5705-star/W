# Luxury Watch Scroll Experience

A clean, responsive, cinematic luxury-watch landing page with a scroll-driven hero.

## Hero sequence
1. Assembled watch
2. Smooth Y-axis rotation toward an 80° turn
3. Transition into the exploded X-axis presentation
4. Final state keeps all major components visibly separated

## Files
- `index.html` — page structure
- `styles.css` — responsive luxury visual system
- `script.js` — scroll-scrubbed hero animation
- `assets/watch-assembled.png` — assembled hero reference
- `assets/watch-exploded.png` — exploded X-axis reference

Open `index.html` in a modern browser to run it.
